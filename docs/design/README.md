# Tally 设计系统

Tally 的视觉语言：**黑白为骨，暖米为底，橙色只做强调**。
结构与配色逻辑沿用 shadcn/ui（`background` / `card` / `muted` / `primary` / `border` / `ring`
等语义 token），但所有中性色都向暖橙偏移，控件全部胶囊化，容器是大圆角卡片。

来源：[Tally Design System](https://claude.ai/artifact/TH5Ybme5ynzwt4QCW72UzC)。原系统面向理财看板，
本目录只保留与业务无关的通用部分（token、基础组件与交互规范），去掉了银行卡、收支图表、
指标卡、金额格式等理财专属内容。系统提供 light / dark 两套主题，样式类名前缀为 `tl-`。

本目录描述目标视觉规范。`apps/palace-web/src/theme.css` 目前仍是原有配色（如绿色 `primary`、
仅 light 主题），尚未迁移到 Tally；现状见[组件与样式](../frontend/组件与样式.md)。

## 设计原则

- **黑白做决定，橙色做强调。** 操作与导航只用 `primary`（黑）和中性色；`brand` 橙只用于内容上的强调，
  不做按钮色。
- **分层靠明度，不靠阴影。** `background` → `card` → `muted` 三层暖色逐级变化，卡片几乎无投影
  （`shadow-sm` 可省略），浮层才用 `shadow-lg`。
- **柔软而克制。** 所有可点的东西都是胶囊（`radius-full`），所有容器都是 `radius-lg` / `radius-xl`；
  不用描边卡片、不用渐变、不用彩色左边框。
- **状态不只靠颜色。** 成功/错误等状态同时用符号或文字表达，不只靠红绿区分。
