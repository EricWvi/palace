# 交互与图标

## 状态

| 状态 | 表现 |
| --- | --- |
| 悬停 | 中性控件底色变为 `accent`；default 按钮降到 88% 不透明度。 |
| 焦点 | `focus-ring`——2px `card` 色间隙 + 2px `ring` 实线，所有面上 ≥3:1。 |
| 禁用 | 50% 不透明度，光标 `not-allowed`。 |
| 动效 | 只做 150ms 的颜色/透明度过渡，不做位移与弹跳。 |

焦点环通过 `box-shadow` 实现以跟随圆角，`outline` 设为透明以保留高对比模式下的可见性：

```css
:where(.tl-btn, .tl-tab, .tl-chip, .tl-rail-item, .tl-input):focus-visible {
  outline: 2px solid #00000000;
  box-shadow: var(--focus-ring);
}
```

## 图标

- 线性图标：24px 网格、1.75 描边、圆角端点、`currentColor`。组件内置一小套（`Icon.names`），
  缺的从 **Lucide** 补（同样的描边语言）。
- 默认 18px；侧栏 22px；图标按钮是 40px `muted` 圆底。
- 不用 emoji，不用填充图标（侧栏当前项靠黑圆底区分，而不是换实心图标）。

内置图标名：`home` `grid` `lock` `doc` `settings` `logout` `search` `bell` `arrowUpRight` `arrowRight`
`plus` `chevronDown` `calendar` `upload` `download` `filter` `sliders` `layers`。
原系统另有 `wallet` `piggy` `receipt` `transfer` `trendUp` `pie` 等理财类图标，未纳入。

## Logo

系统不带 logo：品牌名用 `font-sans` 500 字重排版；logo 由使用方提供。
