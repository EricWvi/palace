# 组件

组件以 React 18 实现，样式类名前缀为 `tl-`。原系统中的 StatCard、PaymentCard、CapsuleChart、
ChartTooltip 属于理财看板专属组件，未纳入。以下“使用者提供”说明调用方需要传入的内容。

| 分组 | 组件 |
| --- | --- |
| 操作 | [Button](#button)、[Chip](#chip)、[Input](#input) |
| 导航 | [NavTabs](#navtabs)、[IconRail](#iconrail) |
| 容器 | [Card](#card)、[ListItem](#listitem) |
| 状态 | [Badge](#badge) |
| 身份与图标 | [Avatar](#avatar)、[AvatarGroup](#avatargroup)、[Icon](#icon) |

## Button

按钮一律是胶囊（`radius-full`）。**default**（`primary` 黑底）每屏最多一个，用于该页真正要做的事，
如 “Export”；其余用 **secondary**（`card` 底，放在 `background` 上）、**outline**（`card` + `input` 边）、
**muted**（卡片内部的图标按钮）或 **ghost**。

- 使用者提供：`children`（动词开头、首字母大写的短标签），可选 `icon` / `iconRight`（Icon 名称），
  `size`：`sm` 32 / `md` 40 / `lg` 48 / `icon`。
- 只有图标时必须给 `aria-label`。
- 不要用 `brand` 橙色做按钮——橙色只做内容强调。

```ts
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'default' | 'secondary' | 'outline' | 'muted' | 'ghost';
  size?: 'sm' | 'md' | 'lg' | 'icon';
  icon?: IconName;
  iconRight?: IconName;
}
```

## Chip

下拉/日期/筛选的触发器：胶囊、`card` 底（卡片内用 `muted`），带图标与下拉箭头。

- 使用者提供：`children`（当前值，如 “All Types”），可选 `icon`，`caret={false}` 去掉箭头，`muted`。
- 它只是触发器；弹出的菜单用 `card` + `shadow-lg` + `radius-md`。

```ts
interface ChipProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  icon?: IconName;
  caret?: boolean;
  muted?: boolean;
}
```

## Input

文本输入：胶囊、`muted` 底、`input` 柔和边，聚焦显示 `focus-ring`。参考设计中没有该组件，
作为 shadcn 式系统的必备组件补充。

- 使用者提供：`label`、`placeholder`、可选 `icon`（左侧）与 `hint`，其余属性透传给 `<input>`。
- 标签在上、提示在下；错误文字用 `destructive`。

```ts
interface InputProps extends React.InputHTMLAttributes<HTMLInputElement> {
  label?: string;
  hint?: string;
  icon?: IconName;
}
```

## NavTabs

顶部主导航：一组透明胶囊，当前项为 `primary` 黑底。放在 `card` 顶栏里；在 `background` 上使用时加 `muted`。

- 使用者提供：`items`（字符串或 `{value,label}`），`value`/`defaultValue`，`onChange`。
- 一组 3–6 项；超过就移到侧栏。

```ts
interface NavTabsProps {
  items: Array<string | { value: string; label: React.ReactNode }>;
  value?: string;
  defaultValue?: string;
  onChange?: (value: string) => void;
  muted?: boolean;
  label?: string;
  className?: string;
}
```

## IconRail

左侧图标导航栏：`card` 底、`radius-xl`，48px 圆形图标按钮，当前页为 `primary` 黑圆。底部组放设置与退出。

- 使用者提供：`items` 与 `footer`（`[{value, icon, label}]`——`label` 作为无障碍名称与 title），
  `value`/`onChange`，可选 `height`。
- 图标 22px、1.75 描边；不放文字标签。

```ts
interface IconRailItem { value: string; icon: IconName; label: string }
interface IconRailProps {
  items: IconRailItem[];
  footer?: IconRailItem[];
  value?: string;
  defaultValue?: string;
  onChange?: (value: string) => void;
  height?: number;
  label?: string;
}
```

## Card

所有内容的容器：`card` 底、`radius-lg`、`space-6` 内边距（`compact` 为 `space-5`），放在 `background` 上，
靠明度而非阴影分层。

- 使用者提供：`title`，可选 `eyebrow`（标题上方小字）、`action`（右上角——
  通常是 `muted` 图标按钮或 Chip），以及 `children`。
- 卡片之间用 `space-4` 栅格间距；卡片内部次级面用 `muted` + `radius-md`。

```ts
interface CardProps extends React.HTMLAttributes<HTMLElement> {
  title?: React.ReactNode;
  eyebrow?: React.ReactNode;
  action?: React.ReactNode;
  compact?: boolean;
  as?: string;
}
```

## ListItem

卡片内的一行：`muted` 底、`radius-md`、左侧头像或图标、中间标题 + 元信息、右侧附加内容。

- 使用者提供：`title`、`meta`，`avatar={{name,src}}` 或自定义 `leading` / `trailing`。
- 行与行之间 `space-3`；右侧数字用 tabular-nums 右对齐。

```ts
interface ListItemProps {
  title: React.ReactNode;
  meta?: React.ReactNode;
  avatar?: { name?: string; src?: string };
  leading?: React.ReactNode;
  trailing?: React.ReactNode;
  className?: string;
}
```

## Badge

短状态标签，胶囊形。`success` / `destructive` 色调的 Badge 文字本身要说明状态，不能只靠红绿区分。

- 使用者提供：`children`，`tone`（neutral · success · destructive · brand · inverse · outline），
  `size="sm"` 用于小卡片。
- 放在所修饰内容的右侧，垂直居中对齐。

```ts
interface BadgeProps {
  tone?: 'neutral' | 'success' | 'destructive' | 'brand' | 'inverse' | 'outline';
  size?: 'sm' | 'md';
  className?: string;
  children?: React.ReactNode;
}
```

## Avatar

圆形头像；无图片时显示姓名首字母（`secondary` 底）。尺寸 `sm` 32 / `md` 40 / `lg` 48。

- 使用者提供：`name`（必填，用于 alt 与首字母），可选 `src`。

```ts
interface AvatarProps { name: string; src?: string; size?: 'sm' | 'md' | 'lg'; className?: string }
```

## AvatarGroup

重叠头像组，超出 `max` 显示黑底 “+N”。每个头像带 2px `card` 色描边隔开。

- 使用者提供：`people`（`{name,src}` 或名字字符串），`max`（默认 4），`size`。

```ts
interface AvatarGroupProps {
  people: Array<string | { name: string; src?: string }>;
  max?: number;
  size?: 'sm' | 'md' | 'lg';
}
```

## Icon

内置的线性图标集：24px 网格、1.75 描边、圆角端点、`currentColor`。默认 18px，导航 22px。
图标名列表见[交互与图标](交互与图标.md#图标)。

- 使用者提供：`name`（见 `Icon.names`），可选 `size`、`label`（有意义时给名称，否则装饰性隐藏）。
- 需要更多图标时用 Lucide（同样的描边语言）。

```ts
interface IconProps { name: IconName; size?: number | string; label?: string; strokeWidth?: number; className?: string }
```
