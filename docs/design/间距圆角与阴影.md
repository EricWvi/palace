# 间距、圆角与阴影

## 间距

4px 基数。卡片之间 `space-4`，小卡片内边距 `space-5`，大卡片 `space-6`，页面外边距 `space-10`。

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-1` | 4px | 图标与小字的间距。 |
| `space-2` | 8px | 图标与标签、胶囊内间距。 |
| `space-3` | 12px | 列表行之间、相关控件之间。 |
| `space-4` | 16px | 卡片之间的栅格间距；列表行内边距。 |
| `space-5` | 20px | 小卡片内边距。 |
| `space-6` | 24px | 大卡片内边距。 |
| `space-8` | 32px | 区块之间。 |
| `space-10` | 40px | 页面外边距（桌面）。 |

## 圆角

柔软、偏圆：所有控件都是胶囊，所有容器都是大圆角。

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-sm` | 10px | 小芯片、tooltip 内元素、复选框。 |
| `radius-md` | 16px | 卡片内部的次级面：列表行、tooltip。 |
| `radius-lg` | 24px | 卡片。 |
| `radius-xl` | 32px | 顶栏、侧栏、应用外框。 |
| `radius-full` | 9999px | 所有按钮、输入框、Badge、头像。 |

## 阴影

几乎无阴影：层级靠 `background` → `card` → `muted` 的明度，而不是投影。

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `shadow-sm` | `0 1px 2px #1714120a` | `0 1px 2px #00000066` | 卡片静止态（可省略）。 |
| `shadow-lg` | `0 12px 32px -8px #1714122e` | `0 12px 32px -8px #000000cc` | 下拉菜单、popover、tooltip。 |
| `focus-ring` | `0 0 0 2px #fffcf9, 0 0 0 4px #171412` | `0 0 0 2px #1b1815, 0 0 0 4px #f7f3ef` | 键盘焦点：2px card 色间隙 + 2px ring 实线（box-shadow，跟随圆角）。 |
