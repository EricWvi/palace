# 颜色

颜色是语义 token，命名沿用 shadcn/ui。light 为主主题，dark 为反转主题；
一个 token 在 dark 下缺值时继承 light 的值。

## 使用规则

- 页面底色 `background`；内容放在 `card` 上；卡片内部的列表行、筛选胶囊、图标按钮用 `muted`；悬停用 `accent`。
- 文字：主文字 `foreground`，次级 `muted-foreground`——两者在三层面上两个主题都 ≥4.5:1。
- 主操作、激活导航、侧栏当前项、tooltip：`primary` 填充 + `primary-foreground`。dark 主题中 `primary` 反转为暖白。
- 品牌橙：填充用 `brand`，淡底用 `brand-soft`，橙色文字用 `brand-ink`（小字也 ≥4.5:1）。
  light 下 `brand-foreground`（白）对 `brand` 仅 3.3:1，只放 18px 半粗 / 24px 以上的字。
- 状态：`success` 在 `success-soft` 上，`destructive` 在 `destructive-soft` 上；同时配符号或文字。
- 分隔线 `border`，输入框边 `input`（柔和，同 shadcn；控件靠 `muted` 填充识别）。

## 表面与文字

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `background` | `#f5efe8` | `#12100e` | 页面底色：淡暖橙米色，所有卡片放在它上面。 |
| `card` | `#fffcf9` | `#1b1815` | 卡片、顶栏、侧栏、弹层的底色——比 background 更亮的一层暖白。 |
| `muted` | `#f8f2ec` | `#24201c` | 卡片内部的次级面：列表行、筛选胶囊、输入框、图标按钮底。 |
| `accent` | `#f1e9e0` | `#2c2723` | 悬停/按下时的面色（ghost、outline 按钮 hover，列表行 hover）。 |
| `secondary` | `#ece4db` | `#302a25` | 次要填充：分段控件轨道、禁用态、中性 Badge 底。 |
| `border` | `#ece3d9` | `#2e2924` | 卡片、分隔线的发丝线（1px）。纯装饰，不承载信息。 |
| `input` | `#ddd2c6` | `#443c35` | 输入框、outline 按钮的边框。对 card 约 1.5:1，不足 3:1：控件靠 muted 填充 + 占位文字识别，聚焦态由 ring 补足。 |
| `foreground` | `#171412` | `#f7f3ef` | 主文字色：标题、数值、正文。在 background / card / muted / accent 上均 ≥12:1。 |
| `muted-foreground` | `#6b625a` | `#a69d94` | 次级文字：说明、日期、元信息。在 background、card、muted 上 ≥4.5:1（两个主题）。 |

## 主色与品牌色

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `primary` | `#171412` | `#f7f3ef` | 主色即黑（dark 为暖白）：主按钮、激活的导航胶囊、侧栏激活圆点、tooltip 底。每屏只一个主操作。 |
| `primary-foreground` | `#fffcf9` | `#171412` | primary 填充上的文字与图标。 |
| `brand` | `#ea6313` | `#f7812e` | 品牌橙：强调填充，如欢迎语中的名字（24px+）。不要当按钮色；不要给小字用。 |
| `brand-foreground` | `#ffffff` | `#171412` | brand 填充上的文字。light 下白字对 brand 为 3.3:1，只用于 18px 半粗 / 24px 以上。 |
| `brand-soft` | `#fde8d7` | `#3a2112` | 淡橙底：品牌色 Badge、选中行。 |
| `brand-ink` | `#b4470c` | `#fb923c` | 橙色文字：链接、小号强调；在 card、background、brand-soft 上 ≥4.5:1。 |

## 状态色

| Token | Light | Dark | 用途 |
| --- | --- | --- | --- |
| `success` | `#137236` | `#4ade80` | 成功文字与图标；在 success-soft 与 card 上 ≥4.5:1。 |
| `success-soft` | `#e3f6e7` | `#12301c` | 成功 Badge 底色。 |
| `destructive` | `#c21d1d` | `#f87171` | 错误/危险文字与图标；在 destructive-soft 与 card 上 ≥4.5:1。配符号或文字，不只靠红绿区分。 |
| `destructive-soft` | `#fde6e6` | `#3a1616` | 错误 Badge 底色。 |
| `ring` | `#171412` | `#f7f3ef` | 键盘焦点环：2px 实线，外加 2px card 色间隙；在所有面上 ≥3:1。 |
