# 对话

对话是 Palace 的一种 Moment 类型。本文描述当前已实现的导入、时间线卡片、阅读与管理行为；
整体时间线与跨 Moment 类型体验见[产品设计](../../product/README.md)，页面地址规则见
`specs/decisions/web/navigation/`。

## 时间线上的对话

一条 Path（一次来源 Session）就是一个 Moment，出现在它 `occurred_at` 所在的本地日期。
`GET /api/timeline?start=&end=` 返回调用方按本地时区算出的 `[start, end)` 内的 Moment，
按 `occurred_at, id` 排序，区间最长 48 小时。对话卡片字段：

| 字段 | 来源 |
| --- | --- |
| `id`、`occurred_at` | Moment，`id` 等于 Path ID |
| `title` | 这条 Path 的标题 |
| `source` | 所属 Conversation 的来源 |
| `message_count` | 从根到这条 Path 末端的消息数 |
| `excerpt` | Path 开头至多两条消息，服务端只读每条正文的前 512 个字符，去掉 Markdown 后截取前 120 个字符 |

卡片显示为 `[ 对话 ] 标题`、`来源 · N 条消息` 和两行摘录。点击标题进入摘星的阅读页
`/conversations/:id?path=<Path ID>&date=<当天>`；对话在时间线上不原地展开。

## 导入

新建导入从时刻页日期标题旁的 `···` 菜单发起（“导入对话”）。发生时间默认取正在浏览的日期
加当前本地时刻，可以改成任意值。成功后：

1. 当前时间线地址被替换为本次发生日期，并定位到新 Moment；
2. 再打开阅读页，返回链接指向同一天。

因此浏览器后退与返回链接到达同一处：对话被归入的那一天。

`POST /api/import` 与 `POST /api/import/file` 均要求 `occurred_at`（JSON 整数 / multipart
十进制字符串），范围为公历 0001–9999 年。发生时间保存在 `moment.occurred_at`，并在
`conversation_import.occurred_at` 记录本次操作值；`created_at` 由数据库生成。
标题和发生时间都参与幂等摘要：相同 key 修改任一项返回 409，相同请求重试返回原结果。

导入 JSON 必须是非空 `[{"role":"user"|"assistant","content":"..."}]` 消息数组；仓库
`examples/` 文件可直接使用，尚不支持任意厂商完整账户导出格式。

## 阅读页

阅读页属于「摘星」，导航中摘星显示为当前项。页首依次是：

- 可选的返回链接「← M 月 D 日」，仅在地址带 `date` 时出现，指向 `/?date=…&moment=<Path ID>`；
- 当前 Path 的标题（也是浏览器标签页标题）及悬停才出现的 `···` 管理菜单；
- `来源 · N 条消息 · 继续对话 ↗`，“继续对话”是当前 Path 的来源链接。

正文是一列消息：说话人小标签，user 消息带浅底色，assistant 不加底色。
`react-markdown` + GFM 展示 Markdown、表格和代码块；不执行原始 HTML、不加载远程图片，
危险 URL 由默认过滤器拒绝。分叉写成一句文字，详见[分支与路径](分支与路径.md)。

窗口宽度不小于 900px 时，右边缘有一列消息目录：当前 Path 的每条消息一条短横线，user
消息的较长，正在读的为实色。指向横线或用键盘进入时展开浮层，每条消息一行开头文字，点击平滑
滚到该消息，并保持标记在这一条直到读者自己滚动。行文字来自消息接口的 `toc_line`：服务端取
`content` 开头 256 字节，按时间线摘录的规则去掉 Markdown，至多保留
48 个字符。

## 管理

标题菜单依次为“更新分支”“管理分支”“编辑对话”“删除对话”：

- **更新分支**：直接更新正在阅读的 Path，见[分支与路径](分支与路径.md#管理分支)。
- **管理分支**：见[分支与路径](分支与路径.md#管理分支)。
- **编辑对话**：标题只改当前 Path，来源改整个 Conversation（级联到全部 Path 的来源与原始链接）。
  目标来源下存在相同 Session ID 时保留输入并提示冲突，服务端不写入部分结果。
- **删除对话**：确认后删除整棵树。从某天进入的回到那一天（`/?date=…`），否则回到 `/`；
  均以替换历史记录的方式跳转，后退不会回到已删除对话。

删除当前正在读的 Path 后，阅读页改为展示剩余 Path 中默认的一条，返回日期不变。
