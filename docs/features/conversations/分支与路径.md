# 对话树与来源路径

属于[对话](README.md)功能；通用前端工程见[前端文档](../../frontend/README.md)。

一个 Conversation 拥有来源和消息树；每个来源 Session 是一个独立 Path，Path 有自己的标题。
同一用户、来源网站下的 Session ID 不可重复，创建新对话不会自动合并已有 Session。

## 接口

| 接口 | 输入或返回 |
| --- | --- |
| `POST /api/import`、`POST /api/import/file` | 创建 Conversation 及首条 Path；标题写入这条 Path |
| `GET /api/timeline` | 按天返回 Moment，对话卡片字段见[对话](README.md#时间线上的对话) |
| `GET /api/conversations/{id}` | `conversation`（来源，无标题）、`messages`、`paths`；每个 Path 含标题、Session ID、末端、消息数、时间及 `original_link` |
| `POST /api/conversations/{id}/paths` | JSON：`title`、`session_id`、`history` 原始 JSON 字符串、`occurred_at` epoch 毫秒、`idempotency_key` |
| `PUT /api/conversations/{id}/paths/{path_id}` | JSON：`title`、`history`、`occurred_at`、`idempotency_key`；Session 身份不变，标题随本次提交替换 |
| `PUT /api/conversations/{id}/paths/{path_id}/metadata` | JSON：`title`（这条 Path）、`source`（整个 Conversation） |
| `GET /api/conversations/{id}/paths/{path_id}` | 对应 Path 的完整消息数组 |
| `DELETE /api/conversations/{id}/paths/{path_id}` | 删除分支、它的 Moment 及不再被引用的消息；最后一个分支请删除整个对话 |
| `DELETE /api/conversations/{id}` | 原子删除整棵树及所有 Path、Moment、导入记录 |

所有导入响应含 `conversation_id`、`path_id`、`head_message_id`、创建和复用消息数量。
三种导入都必须携带合法标题；分支接口仍拒绝来源和 Owner，更新不接受 Session ID。
重复 Session 返回 409 `session_already_exists`。

新分支需从根开始共享至少到一个 assistant 节点的完整前缀。更新必须上传完整 JSON，
只能追加或保持全部原历史，不能截短、改写或重排。比较严格使用原始 role/content，不做文本规范化。

`occurred_at` 是用户填写的发生时间，追加更新会把 Moment 移到新的日期；
`created_at` 和 `updated_at` 是数据库记录的时间。同键同请求的幂等重试不改变时间和标题；
失败时消息、标题和时间一起回滚。默认阅读路径按 `updated_at DESC, id DESC` 选择。

需要以 Conversation 为单位显示名称时，取 `created_at, id` 最小的 Path 的标题，不另外保存。

## 分支管理

阅读页标题菜单的“分支管理”打开对话树。树图只显示 user 消息摘要，单行省略；末端落在同一
user 节点的多个 Session 分别提供“更新”“删除”文字按钮。树图使用 React Flow 与 Dagre
自上而下布局，支持拖动画布、缩放与适应画布；节点操作在悬停或键盘聚焦时显示，触屏保持可见。

新建分支的标题默认取正在阅读的 Path 的标题，可以修改；来源跟随 Conversation，不可修改。
更新分支回填该 Path 的标题与 `occurred_at`，都可以修改，Session ID 不可修改。
导入成功后关闭管理弹窗，阅读页切到本次 Path，返回日期改为本次发生时间所在的日期。

## 分叉

阅读页在每个分叉点下方显示一句文字：“此处分为 K 支：选项 · 选项”。普通选项取该分支下一条
消息的前 14 个字符，当前选项带 accent 色下划线。Path 在内部节点结束时选项为“在此结束”，
同一末端有多个 Session 时显示为“在此结束 · Session ID”。选择后续使用该子树内更新时间最新的
Path，不拼接不同 Path 的后缀；地址中的 `path` 以替换历史记录的方式更新。

## 迁移

- `0007_conversation_paths.sql`：将单路径 Conversation 的 Session ID 移到新 Path，保留 Conversation/Message 身份。
- `0009_moments.sql`：新建 `moment` 表，每条 Path 成为同 ID 的对话 Moment，发生时间从 Path 移到 Moment；
  延迟检查的约束触发器保证每个 Moment 恰好有一条详情。
- `0010_path_titles.sql`：把 Conversation 标题复制给它的每条 Path，再删除 `conversation.title`。此步不可逆。

服务启动自动运行迁移；测试只在独立 PostgreSQL 容器运行，不修改用户数据。

## 验证

`task test:integration` 验证有数据迁移、Moment 与详情配对、按天查询、卡片字段、跨 Owner 隔离、
前缀复用、并发 Session 唯一性、追加限制、标题幂等、失败回滚、共享节点删除和 HTTP 契约。
`task test:frontend` 验证分叉切换、内部末端、标题与返回日期、管理菜单及请求字段；
`task test:browser` 验证真实浏览器中的往返导航、导入落点、悬停菜单、树图布局和移动端边界。
浏览器测试默认使用 5173 端口；端口占用时可设置 `PALACE_BROWSER_TEST_PORT` 使用独立端口。
