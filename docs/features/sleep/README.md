# 睡眠

时刻页上的睡眠记录：晚上从日期旁的 `···` 菜单开始，醒来在表盘上结束，这一晚以表盘置顶醒来那天；点表盘进入睡眠历史页。决策见[睡眠 ADR](../../../specs/decisions/web/sleep/0-sleep-started-from-the-day-menu-pinned-as-a-dial.md)，交互原型见 [`design/2.2-moment-sleep.html`](../../../design/2.2-moment-sleep.html)。只记入睡和醒来两个时间，没有分期、评分和心率。

## 一晚

- **归日**：一晚是一个 `sleep` Moment，`occurred_at` 是醒来时间，按浏览器时区落在醒来那天。
- **时间段**：`[入睡, 醒来)`，长度大于零、不超过 24 小时；同一个人的两晚不能重叠，相接可以。
- **计时中的开始**：每人至多一个，不是 Moment，不进时间线。再次开始会替换它，所以忘记结束的开始会在下一次开始时消失。

## 钟点规则

都按浏览器的本地时间判断，服务端不知道这些钟点。

| 时间 | 今天的菜单 | 今天的置顶 |
| --- | --- | --- |
| 18:00–05:00，没有在计时 | 「开始睡眠」 | 今天归入的一晚（若有） |
| 计时中 | 没有睡眠项 | 计时表盘，右侧停止按钮 |
| 05:00–15:00，没有在计时、今天还没有一晚 | 「记录睡眠」 | 无 |
| 15:00–18:00 | 没有睡眠项 | 今天归入的一晚（若有） |

- 06:00 前（含前一晚 18:00 之后）点停止按钮，先问「现在就结束睡眠？」，默认「继续睡」。
- 到开始那晚之后的 15:00 仍在计时，表盘消失，像没有开始过。
- 「记录睡眠」只填两个钟点：入睡在 12:00 及以后的算前一天晚上，之前的算当天凌晨；醒来不能晚于现在，全程不超过 16 小时。默认填近几晚的平均入睡与醒来时间。
- 以前的日子只显示那天的一晚，菜单里没有睡眠项。

## 页面

- 时刻页：日期下置顶表盘，显示时长、入睡与醒来时间，以及截至这一晚的 7 晚柱（没有记录的一天是贴底的短横）。睡眠不再出现在下面的列表里；一天只有睡眠时也不显示“这一天还没有记录。”。
- 历史页 `/sleep?date=…`：返回链接回到来源日期。顶部是近 30 晚的平均时长、平均入睡和平均醒来；下面最近一年每天一行，最新在上，按周分隔，每行把这一晚画在 20:00 到次日 10:00 的夜轴上。点有记录的一行修改或删除（删除要再点一次「确认删除」），点「无」的一行补记。

## 接口

| 方法与路径 | 作用 |
| --- | --- |
| `GET /api/sleep/running` | `{ started_at }`，没有在计时时为 `null` |
| `PUT /api/sleep/running` | 以服务端当前时间开始，替换已有的开始 |
| `POST /api/sleep/running/end` | `{ started_at }`，以服务端当前时间结束并返回这一晚；`started_at` 不是当前的开始时 404；重复请求返回同一晚 |
| `GET /api/sleep/nights?start=&end=` | 醒来时间在 `[start, end)` 内的夜晚，按醒来时间排序；区间不超过 400 天 |
| `POST /api/sleep/nights` | `{ started_at, ended_at }` 补记，返回 201 |
| `PUT /api/sleep/nights/{id}` | 修改时间段，Moment 随醒来时间移到新的日子，身份不变 |
| `DELETE /api/sleep/nights/{id}` | 连同 Moment 删除，返回 204 |

时间都是 epoch 毫秒。与已有的一晚重叠返回 409；超过 24 小时、结束不晚于开始返回 400 并指出字段。时间线接口返回 `{ "kind": "sleep", "id", "occurred_at", "started_at" }`。其他 Owner 的夜晚和开始都返回 404。字段的完整定义见 [OpenAPI](../../../contracts/openapi.json)。
