# Palace 前端工程

前端承载 Palace 的整体产品体验。产品方向是按日期浏览时间线、通过内容卡片进入类型化详情，
见[跨端形态](../product/跨端形态.md)。这些产品约定包含后续建设目标。

当前 Web 应用位于 `apps/palace-web/`，已实现对话收藏、导入、阅读及分支管理；
通用时间线和其他内容类型不能据此视为已实现。对话的业务规则放在[对话功能](../features/conversations/README.md)，
本目录记录各功能共同使用的工程能力。

## 文档导航

- [开发与验证](开发与验证.md)：本地联调、构建、部署边界和测试入口。
- [API 客户端](API客户端.md)：生成类型、同源凭证、错误处理及文件上传。
- [组件与样式](组件与样式.md)：UI 基础组件、主题和 shadcn registry。

## 当前技术边界

- React 19 + Vite + TypeScript，React Router 管理页面路由。
- React Query 管理服务端数据与 mutation；Zustand 保存临时界面状态，不复制服务端记录。
- 通用组件和主题由前端工程维护，内容类型的摘要、详情与专属操作归各功能文档。
- 认证与 Session 的服务端行为见[认证系统](../server/认证系统.md)。

新增内容类型时，在 `docs/features/` 下记录该类型的发生时间、摘要、详情与专属操作；
跨内容类型的产品约定继续维护在 `docs/product/`。
文档目录用于组织实现知识，不要求每种内容拥有独立一级页面。
