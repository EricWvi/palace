# Echoes：周期回顾

[返回总览](../../README.md) · [截图](../../screenshots/Echoes.png) · [完整问题清单](questions.md)

Echoes 分 Week、Year、Decade 三个页签。周回顾是一篇带问题模板的文档；年与十年回顾按固定问题组织，便于比较自己在不同时期对同一问题的回答。

## 页面与表

| 页签   | `d_echo` 定位                                          | 界面组织                                           | 正文                                  |
| ------ | ------------------------------------------------------ | -------------------------------------------------- | ------------------------------------- |
| Week   | `e_type=Week`，`year` 为周所属年，`sub` 为周号         | 按年折叠，按周显示按钮；已有记录实底，待补记录虚线 | 一周对应一个 `draft`，含 8 个问题段落 |
| Year   | `e_type=Year`，`year` 为年份，`sub` 为问题编号         | 41 个问题，每题展开显示不同年份答案                | 每个问题 / 年份独立 `draft`           |
| Decade | `e_type=Decade`，`year` 为区间结束年，`sub` 为问题编号 | 41 个问题，每题显示不同十年区间                    | 每个问题 / 区间独立 `draft`           |

三者都通过 `draft → d_tiptap.id` 保存答案，附件间接使用 `d_media`。周重点标记使用 `d_echo.mark`。没有独立问题表；问题编号和中英文文案在前端常量中，因此仅迁移数据库会丢失题目含义。

## E01：撰写本周回顾

进入 Week 默认展开本年。本周按钮没有正文时，创建包含 8 个三级标题及空段落的 Tiptap 文档，再新增对应 `d_echo` 并打开编辑器；有正文时直接进入原文档。

上周没有记录时显示虚线补写按钮；当处于第 1 周时，上年区域还提供年末周补写分支。上年区域本身由已有年份列表驱动，没有该年份数据时未必会出现补写入口。

周模板包括有意义的时刻、挑战、值得骄傲的事、快乐与感激、精力消耗、支持、启示和自由补充。正文是普通富文本，可以继续修改段落，不是八个独立表单字段。

## E02：回看并标记重要的一周

点击历史周按钮，弹框展示周号、日期范围和只读正文；点击角落标记切换 `mark`，列表按钮同步显示紫色书签样式。

历史周弹框对“上一周”提供编辑入口，其余通常只读。代码判断主要比较周号，未在该编辑条件中完整校验年份；不能把界面时间限制当成严格权限规则。后端通用文档更新也不校验 Echo 的可编辑时间窗口。

## E03：回答年度问题并对照往年

展开某个问题，点击当前年份按钮，按需创建一份空文档与 `d_echo`，然后作答。点其他年份可只读查看同题答案。上一年的答案在当前一、二月显示补改入口（`getMonth()<2`）。没有任意选择缺失历史年份并补建答案的通用入口。

当前年份使用 `getWeekYearPair().year`，年初第一个周一前可能仍归上一年，不能只按普通日历年推断所有按钮。

## E04：回答十年问题

每题的当前区间可创建 / 编辑答案；历史区间只读。上一区间在结束后的次年提供编辑入口。当前区间的发布版算法是 `start=year-year%10+1`、`end=start+9`；例如 2026 得到 2021–2030。

边界须保留说明：2030 按此公式已经切到 2031–2040，尽管界面名称看起来像 2030 应属于上一段。这是旧算法的边界问题，不能直接把它描述为严密的自然十年规则；导入应优先保留已存 `year` 与答案归属，Palace 另定新建区间算法。

## 周号与创建约束

周号按当年第一个周一为第 1 周，其前日期归上一年末周，不等于 ISO 周号。历史记录的 `year/sub` 与 `getWeekRange` 一起解释。

创建答案是“先正文、后 Echo”两次请求；模型未定义 `(creator_id,e_type,year,sub)` 唯一约束，不能假定旧库必然一周期一条。该版没有通用 Echo 删除、题目管理、自定义周期或提醒功能。正文编辑与历史见[共享编辑器](../../shared/editor-and-history.md)。

## 迁移核对

- 周回顾按一篇正文导入；年 / 十年按问题编号保留对应关系。
- 周重点标记、旧日期范围和所有历史答案保留。
- 检查重复周期记录，保留可解释的来源，不能任意覆盖。
- 问题模板、编辑时间窗口和边界问题与数据分别记录，不把旧前端限制当新产品权限设计。
