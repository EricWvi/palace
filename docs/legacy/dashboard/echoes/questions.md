# Echoes 问题清单

[返回 Echoes](README.md)。以下中文题目逐项提取自 `v2.17.3` 的前端常量，保留原编号与措辞。年度与十年答案依靠编号关联；问题文字不在数据库里。

周模板的八题共同组成一份正文；年度与十年分别为 41 个问题，每题各有独立答案文档。这里列中文内容，原文件还包含英文文案；迁移双语模板时应一起保留。
