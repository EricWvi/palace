# Journal 检索与回顾用例

[返回 Journal](README.md)。一般过滤查询 `d_entry`，同批返回关联的 `d_tiptap` 正文；标签 / 地点候选另外读取 `d_tag`。

## N08：按时间阅读全部手记

默认按 `created_at DESC` 返回，每页 8 条，向下滚动继续加载。客户端按今天、昨天和月份分组，跨年时显示年份；无结果显示空状态，全部加载完成显示结束。

筛选变化后清空旧结果、从第一页重新查询并按需要回到顶部。普通筛选不改写手记；随机回顾例外，会更新计数。

## N09：搜索正文

点击搜索图标输入关键词并提交，添加 `contains` 条件，后端对 `raw_text` 执行不区分大小写的 `ILIKE '%关键词%'`。新搜索替换旧搜索项，提交空文本会移除搜索项。

这是单个文本包含条件，不是分词、多关键词布尔语法、语义搜索或对附件进行 OCR。是否能找到刚修改的正文取决于 `raw_text` 是否已经由编辑回调更新。

## N10：定位某天，或从某日向前阅读

| 入口                | 条件                | 精确范围                                        |
| ------------------- | ------------------- | ----------------------------------------------- |
| 年度活动日历点某天  | `on=YYYY-MM-DD`     | 当日起点 ≤ `created_at` < 次日起点              |
| 工具菜单 Date Range | `before=YYYY-MM-DD` | `created_at` < 次日起点，即包含所选日的截至日期 |

Date Range 子菜单按有记录的年 / 月 / 日提供三级选择，换年 / 月会调整下级，点击勾号应用。它没有开始日期 + 结束日期的双端范围选择。新日期条件替换旧 `on / before` 条件。

菜单没有日期条件时显示 Today 占位文字，不代表默认列表只查询今天；默认仍是全部手记。

## N11：按标签或地点回顾

标签菜单一次选一个 `tag`，后端检查 `payload.tags` 包含该值。再次选择替换原标签条件，并非多标签 AND 筛选。

地点菜单允许选至一级、二级或三级后确认，后端按 `payload.location` 的对应数组位置匹配前缀：选“上海”包含其下所有地点；选“上海 / 徐汇”进一步收窄。同名末级地点不会跨父级混合。

这些条件可以和搜索、日期、收藏、历史今天叠加。普通条件由后端逐个追加，因此总体是 AND。页面将条件展示成可单独删除的标签，多项时可一键清除。

## N12：集中查看收藏手记

菜单 Show Bookmarks 添加 `bookmarked` 条件，只返回 `bookmark=true`；已有该条件时不会重复追加。可以进一步筛关键词、时间或地点，删除条件回到原有其余筛选范围。

## N13：历史上的今天

菜单 Today in History 添加 `todays`，后端以服务端当前月 / 日匹配 `created_at` 的月 / 日，不限制年份，结果仍按时间倒序分页。

实现没有额外排除今年，所以今年今天的手记也可能出现。“历史今天”不能简单写成“仅往年同日”。无匹配时显示空状态。

## N14：随机回顾较少看过的记录

选择 Shuffle Entries 会清除现有条件，只保留 `random`。实际算法不是把当前结果随意打乱：

1. 在当前用户未删除手记中找最小 `review_count`。
2. 找出包含该最小计数手记的不同日期。
3. 随机抽取最多 **8 个日期**。
4. 返回这些日期中计数等于该最小值的所有手记，再按 `created_at DESC` 排列。
5. 异步将返回记录的 `review_count+1`；本次响应 `hasMore=false`，不继续分页。

所以返回数可能超过 8 篇；同日已有更高计数的手记不一定一起返回。计数增加发生在查询返回阶段，不证明用户逐篇实际读过。再次点击会重新抽取；增加任何普通筛选时前端会移除 random，恢复常规检索。后端 random 分支也不使用普通条件拼出的过滤范围。

## N15：查看统计与年度活动日历

顶部统计显示：

| 指标              | 来源与口径                                     |
| ----------------- | ---------------------------------------------- |
| Entries This Year | `GetCurrentYear`，当前年 1 月 1 日起的手记数量 |
| Words Written     | `SUM(d_entry.word_count)`，全部手记字数之和    |
| Days Journaled    | 按 `created_at` 年月日去重后的日期数，全部年份 |

点击统计区展开 / 收起当年热力日历，日期色阶为 `min(当日篇数, 4)`。点击日期进入 N10 的单日筛选。统计不随当前搜索结果缩小。

年度接口实际仅加年初下界，没有下一年上界；正常数据来自当前时间的新建记录，但若导入未来日期，这个口径可能把未来记录算入。日期切分同时依赖数据库、服务端及浏览器时区，融合时需统一解释。

## 迁移核对

- 一天多篇的篇数、天数与总字数各自正确。
- “截至某日”包含当天；没有过滤时的 Today 文字不限制查询。
- 搜索 + 单标签 + 地点前缀 + 收藏按交集过滤。
- 随机回顾按最低计数抽日期，不是固定 8 篇；保留 `review_count` 避免迁移后丢失回顾均衡。
- 历史今天包含当前年同日，边界日期以本地时间核对。
