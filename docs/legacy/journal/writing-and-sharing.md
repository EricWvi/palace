# Journal 写作与分享用例

[返回 Journal](README.md)。手记元信息在 `d_entry`，正文在 `d_tiptap`，附件文件在对象存储中并由 `d_media` 映射。

## N01：新建手记

1. 点击底部 / 右下角加号。
2. 前端先创建空 Tiptap 文档，再创建指向该文档的 `d_entry`，打开共享编辑器。
3. 输入文字、富文本、图片或视频。正文按共享编辑规则自动保存。
4. 保存关闭时，如内容有修改，前端通过编辑器纯文本计算 `word_count`，并将去首尾空白、连续空白折叠后的内容写入 `raw_text`。
5. 刷新统计和时间流，显示新卡片。

`raw_text` 供搜索使用，不是正文原件；`word_count` 由 `alfaaz.countWords` 计算，不是简单字符长度。创建与正文绑定是两次请求，正文保存与摘要更新也不是同一事务。

没有编辑直接关闭仍保留已创建的空手记。放弃修改是把正文还原为进入编辑器时的内容，不会自动删除 `d_entry`。不要把新建按钮理解为“只有发布成功才落库”。

## N02：编辑已有手记

卡片菜单 Edit 打开原 `draft`，保存后更新该正文和检索摘要 / 字数，刷新相关查询。手记 ID、日期、收藏、标签地点保持原归属。

正文每 5 秒自动保存，但摘要 / 字数只在 Journal 编辑关闭回调中更新。页面中断、历史恢复或只完成自动保存时，两者可能暂时不一致；导入到 Palace 时可从正文重建搜索文本和字数，而不是假设旧摘要永远准确。

## N03：为手记添加标签与三级地点

卡片 Tags 和 Location 菜单都打开同一个元信息弹框：

- 标签可多选已有项或输入新词。
- 地点最多三级，每级单选但允许新建词；先选一级，再选二级、三级。
- 改变一级会清空当前二、三级选择，改变二级会清空三级，避免拼出错误路径。
- 保存将 `payload.tags` 和 `payload.location` 一起写回手记；地点省略未填末级。
- 前端再把新标签 / 各级地点路径补入 `d_tag`，`t_group=journal`，分别使用 `tag:`、`loc:` 前缀。

例如选择“上海 / 徐汇 / 某公园”，手记保存数组，词库可有 `loc:上海`、`loc:上海/徐汇`、`loc:上海/徐汇/某公园`。这里没有独立地点表、GPS 自动采集或地图选点。

## N04：收藏与取消收藏

卡片菜单 Bookmark / Unbookmark 切换 `d_entry.bookmark`，卡片显示收藏装饰。它不创建 Dashboard 的 `d_bookmark`，也不复制正文；随后可以通过 Journal 的 Show Bookmarks 检索。

## N05：删除手记

卡片菜单 Delete 直接调用 `DeleteEntry`，成功后刷新统计与列表；此调用链没有额外删除确认框。后端软删除 `d_entry`，不级联删除 `d_tiptap` 或媒体。没有 Journal 回收站 / 恢复入口。

## N06：阅读长文与查看多媒体

卡片把正文顶层的 image / video 节点抽到媒体区，其余内容渲染成文字区。长文字默认折叠，超过高度后提供展开阅读。卡片底部显示日期、星期与时间。

媒体区按数量拼图，超过 5 项时显示前几项和剩余数量入口；视频缩略块显示可读取到的时长。缩略图裁剪只影响卡片显示，不改变正文引用的媒体内容。

点击媒体从对应位置进入全屏查看器；支持左右滑动、前后切换和分页导航，视频可播放，图片支持查看器的缩放交互，关闭后回到列表。正文中嵌套在其他节点下的媒体不会被当前顶层抽取逻辑统一收进媒体区，迁移不能只取卡片提取结果而丢掉原文档结构。

媒体展示与原始正文是两种呈现，导入以完整 `d_tiptap.content` 为准。删除 / 调整正文节点不等于已经删除对象存储文件。

## N07：生成分享图片

卡片菜单 Share 创建离屏分享卡，包含用户头像、昵称、手记日期、完整正文、地点路径及 Journal 标记，使用 `html-to-image` 渲染 PNG 并自动下载，随后关闭分享流程。

该操作不修改 `visibility`，不创建分享记录或公开链接。依赖头像、正文图片等加载成功；视频不能因导出 PNG 就视为完成了可播放视频分享。页面也没有服务器生成分享文件的后台任务。

## 迁移核对

- 纯文本、富文本、仅图片、图片与视频混排的手记均可创建和重新编辑。
- 新建空记录、放弃编辑、删除手记的语义明确，不能误把正文历史当回收站。
- 一级地点改变时下级联动；不同父级同名地点保持区分。
- 收藏不复制内容，分享不改变可见性。
- 原正文、检索文本、统计值分清权威与派生关系。
