# Palace 产品设计

Palace 的核心体验是：把个人生活与工作中产生的内容，按发生时间组织成一条可浏览的时间线。

时间线上的每一条内容都是一张卡片。卡片负责在时间线上提供快速概览；用户点开卡片后，在同一条产品体验中查看该内容的完整信息和专属操作，不需要为每一种内容建立一个独立的一级页面。

## 一句话模型

```text
某一天的时间线
  └── 多张内容卡片
        └── 一种内容类型 + 发生时间 + 摘要
              └── 点开后查看完整详情与专属信息
```
