# Palace 产品设计

Palace 的核心体验是：把个人生活与工作中留下的 Moment（时刻），按发生时间组织成一条可浏览的时间线。

时间线上的每个 Moment 都以一张卡片出现。卡片负责在时间线上提供快速概览；用户点开卡片后，在同一条产品体验中查看该 Moment 的完整信息和专属操作，不需要为每一种 Moment 建立一个独立的一级页面。

## 一句话模型

```text
某一天的时间线
  └── 多张 Moment 卡片
        └── 一种 Moment 类型 + 发生时间 + 摘要
              └── 点开后查看完整详情与专属信息
```
