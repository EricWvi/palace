# 会话收藏 Web

后端提供 `GET /api/conversations`，只返回当前 Owner 的会话。每个会话取
`imported_at DESC, import id DESC` 的第一条导入记录，列表按该时间降序、会话 ID
降序排列。返回 `id/title/source/session_id/imported_at/head_message_id/message_count`。
`imported_at` 为 epoch 毫秒；界面按浏览器本地时区展示和输入。

`POST /api/import` 与 `POST /api/import/file` 均要求 `imported_at`（JSON 整数 / multipart
十进制字符串），范围为公历 0001–9999 年。导入时间参与幂等摘要，相同 key 修改时间会
返回 409。时间保存到原有 `conversation_import.imported_at`，不需要迁移。

相同 Owner、来源与 Session ID 合并到同一会话，复用相同消息前缀、保留分支，且保留
已有标题。首页打开最新日期导入的路径；导入成功直接打开本次导入的路径。路径接口
验证祖先关系，不将树中其他分支拼接为聊天。

## 本地开发

需要 Node.js 24+、可用 Docker/Podman 和已有 `postgres:17-alpine` 镜像。

```bash
npm ci
# 终端 1：Origin 与 Vite 页面保持一致
PALACE_ORIGIN=http://127.0.0.1:5173 task run:test-server
# 终端 2
task run:web
```

打开 `http://127.0.0.1:5173`。Vite 固定 5173 端口，将 `/api` 和 `/auth`
代理到 `http://127.0.0.1:8080`，保留浏览器 Origin 供后端校验。不要改用
localhost 访问；地址或端口变更时应同步修改 Vite 和 `PALACE_ORIGIN`。
生产 OIDC 的 Secure cookie 需要 HTTPS，同源部署时才走完整登录流程。

`task build:frontend` 生成 `apps/palace-web/dist`。当前由 Vite 开发服务提供页面；
后续 server 托管此目录时，`/api/*`、`/auth/*` 保持各自路由，其他前端页面
（含 `/conversations/:id` 深链接）需要回退 `index.html`。
本次没有接入生产静态文件路由。

## 代码边界

- React 19 + Vite + TypeScript；React Router 提供独立会话 URL。
- React Query 管理服务端记录和导入 mutation；Zustand 仅保存临时搜索状态，不复制服务端数据。
- `src/components/ui` 是从 shadcn registry 获取并本地修改的源代码；Radix 负责弹层交互，React Day Picker 提供日历。
- `src/theme.css` 是 Palace 配色和 token，`src/styles.css` 是页面布局，支持手机宽度。
- `react-markdown` + GFM 展示 Markdown、表格、代码块；不执行原始 HTML、不加载 Markdown 内的远程图片，危险 URL 由默认 URL 过滤器拒绝。
- JSON 必须是非空 `[{"role":"user"|"assistant","content":"..."}]` 消息数组；仓库 `examples/` 文件可直接使用。尚不支持任意厂商完整账户导出格式。

## 自有 shadcn style

`registry.json` 中的 `palace-style` 使用 `type: "registry:style"` 与
`extends: "none"`，打包本地组件、CSS 文件、CSS variables 和依赖。
这符合 [shadcn 自定义 style 文档](https://ui.shadcn.com/docs/registry/examples)。
`components.json` 的 `style: "new-york"` 只是 CLI 获取官方起始组件的配置，
不是 Palace registry 的继承关系；应用实际视觉由本地源码与 token 决定。

```bash
npm run registry:build -w apps/palace-web
```

构建结果在 `public/r`，运行 Vite 后可访问 `/r/palace-style.json`。
其他 Tailwind v4 项目可通过 `npx shadcn add http://127.0.0.1:5173/r/palace-style.json`
安装，并在主 CSS 的 Tailwind import 之后导入生成的 `src/theme.css`。
该 registry 面向 light mode，目前不定义 dark theme。

## 验证

- `task test`：TypeScript/ESLint、前端交互测试（stderr 必须为空）、Rust 格式、Clippy 和默认测试。
- `task test:integration`：真实 PostgreSQL 上的时间持久化、列表排序、Owner 隔离、导入幂等与 HTTP 文件导入回归。
- `npm exec playwright install chromium` 后，运行 `npm run test:browser -w apps/palace-web`：真实 Chromium 检查桌面/手机、日历、文件选择、页面导航、深链接刷新。此层使用受控 HTTP 响应，不代替真实数据库测试，也不向本地个人数据写入测试会话。
- `task build:frontend` 和 registry 构建验证可交付产物。
