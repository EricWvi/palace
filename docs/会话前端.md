# 会话收藏 Web

后端提供 `GET /api/conversations`，只返回当前 Owner 的会话。每个会话取
`imported_at DESC, import id DESC` 的第一条导入记录，列表按该时间降序、会话 ID
降序排列。返回 `id/title/source/session_id/imported_at/head_message_id/message_count`。
`imported_at` 为 epoch 毫秒；界面按浏览器本地时区展示和输入。

`POST /api/import` 与 `POST /api/import/file` 均要求 `imported_at`（JSON 整数 / multipart
十进制字符串），范围为公历 0001–9999 年。导入时间参与幂等摘要，相同 key 修改时间会
返回 409。时间保存到原有 `conversation_import.imported_at`，不需要迁移。

相同 Owner、来源与 Session ID 合并到同一会话，复用相同消息前缀、保留分支，且保留
已有标题。首页打开最新日期导入的路径；导入成功直接打开本次导入的路径。路径接口
验证祖先关系，不将树中其他分支拼接为聊天。
