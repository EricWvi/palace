运行方式与 API 见 [README](README.md)。核心用例的逐项证据位于 `specs/test-cases/server/`；`Partial` 表示测试没有直接覆盖完整义务，不能当作已验证。例如浏览器 SSO 交互、所有冒充输入变体与未来 Markdown 展示/Owner 导出仍有对应边界。

本次没有开放 Conversation/Message/Import 的多记录结构同步、正文编辑、级联删除、共享、Owner 迁移和数据导出。这些行为已经在 ADR 中明确留给后续协议；当前独立记录同步接口不能用来改写导入树。也未交付 Web 或原生客户端界面。

所有容器测试只检查并使用已经准备的 `postgres:17-alpine` 和 `authelia/authelia:4.39.20`，通过现有 Docker API/Podman socket 启动独立容器；缺少镜像直接失败，不执行安装或镜像下载。默认测试不需要容器。
