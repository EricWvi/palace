# 标题菜单加“导出分支”，导出格式即导入格式

阅读页标题菜单在“管理分支”之后加“导出分支”：把正在阅读的 Path 从根到末端的消息下载为一个 JSON 文件，文件名是该 Path 的标题加 `.json`。

当前为 `implemented`，核心测试用例见[对话阅读页](../../../test-cases/server/conversation/reading-page.md#exporting-a-branch-must-write-the-import-format)。继承[分支管理改为分支列表](20261006-branch-list-and-update-from-title-menu.md)除不变量 1 以外的全部决策，修改其不变量 1 的菜单项。

## 继承与修改

| 前序约定 | 本决定 |
| --- | --- |
| 标题菜单依次为“更新分支”“管理分支”“编辑对话”“删除对话”（20261006 不变量 1） | 修改：在“管理分支”之后加“导出分支”，见 D1 |
| 导入、新建分支与全量更新上传 `[{"role","content"}]` 消息数组 | 继承：导出写同一格式，见 D2 |

## D1：导出正在阅读的 Path

导出与“更新分支”一样只作用于正在阅读的 Path，不经过分支列表。它不改数据，所以排在“管理分支”之后、“编辑对话”之前，不可撤销的“删除对话”仍在最后。文件名直接用 Path 标题，文件名里不允许的字符交给浏览器处理。

## D2：导出格式与导入格式相同

文件是消息数组，每项只有 `role`（`user` / `assistant`）与 `content`，顺序从根到末端。导出的文件可以原样作为全量历史再次导入、新建分支或更新分支。消息 ID、树结构和标注不导出：导入格式里没有它们，导出也不另立一种格式。

导出完全在浏览器内完成，用阅读页已经取得的消息，服务端接口不变。

## 不变量

1. 标题菜单的五项及其顺序固定为“更新分支”“管理分支”“导出分支”“编辑对话”“删除对话”。
2. 导出文件只含当前 Path 的消息，格式与导入格式相同，文件名为 Path 标题加 `.json`。
